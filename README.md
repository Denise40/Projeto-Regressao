# Projeto de Regressão para Materiais de Construção
Construção de um modelo de regressão para prever a resistência do concreto com base em variáveis como cimento, água e outros componentes. Assim, será possível compreender como os diferentes fatores influenciam a resistência do concreto para otimizar a produção e garantir que o concreto atenda aos requisitos necessários.
